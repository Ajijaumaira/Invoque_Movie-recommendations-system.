# Movie Recommendation System

## Project Description
This project recommends movies based on their similarity to a movie selected by the user. It uses movie details such as genres, keywords, cast, crew, and overview to find similar movies.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Google Colab

## Dataset
The project uses:
- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

## Steps Performed
- Loaded and explored the datasets
- Merged the datasets using the movie title
- Selected relevant movie features
- Processed movie information
- Calculated similarity between movies
- Generated movie recommendations

## Recommendation Method
The system uses **content-based filtering** to recommend movies with similar features.

## Outcome
The system suggests similar movies based on the movie selected by the user.
